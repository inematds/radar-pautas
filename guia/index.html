As 6 pautas de IA do dia, com a fonte conferida

Um comando lê 20 fontes (blogs das empresas, imprensa e fóruns) e o GitHub em alta e devolve o que está quente agora, cada pauta com um link que abre e, se você pedir, manchete e gancho em português.

Começar o guia Ver no GitHub
Em resumo

O radar-pautas é um script (um pequeno programa que você roda no terminal) que lê, de uma vez, cerca de 20 sites de notícias de inteligência artificial e os projetos que mais ganharam estrelas no GitHub na semana, e devolve as 6 pautas mais quentes das últimas 24 horas. Serve para quem produz conteúdo e precisa decidir rápido o assunto do dia. Ele junta a mesma notícia vinda de vários sites, dá uma nota, confere se o link abre e, se você pedir, sugere manchete, gancho e formato em português. Precisa só de Python 3; o GitHub CLI e o Claude Code são opcionais.

O que é

Da enxurrada de notícias a uma lista curta

Em vez de abrir 20 abas toda manhã, você roda um comando e recebe 6 assuntos já ordenados. A imagem resume as 6 etapas principais; a seção seguinte mostra o caminho completo.

📰 Mesma notícia, um assunto só

Quando três sites falam do mesmo lançamento, o radar junta tudo numa pauta e dá mais pontos a ela. Notícia que aparece em vários lugares sobe; notícia de um site só fica mais abaixo.

🔗 Só entra link que abre

Antes de mostrar, ele abre o link de cada pauta. Se a página não responde "ok" (o código 200 da internet), tenta outro site do mesmo assunto; se nenhum abrir, a pauta fica de fora.

💡 Ângulo pronto para gravar

Com --angulos, o Claude Code sugere para cada pauta uma manchete em português, por que ela importa, a frase de abertura e o formato. É sugestão: o número e o fato você confere na fonte.

Como funciona

O caminho de uma rodada

Tudo roda no seu computador. Só lê páginas públicas (os feeds RSS dos sites, a lista de novidades que cada site publica) e o GitHub pelo programa gh. Nenhuma chave de API.

Lê 20 feeds + GitHub→ Fica com as últimas 24 h→ Junta a mesma notícia→ Dá nota→ Confere o link→ Já fizemos?→ Ângulo (opcional)→ pautas.md + radar.html

As fontes

Ficam no arquivo fontes.json: blogs da OpenAI, Google AI, Google DeepMind, Hugging Face, NVIDIA, Mistral e GitHub; imprensa (The Verge, TechCrunch, Ars Technica, Wired, The Decoder, MarkTechPost, MIT News); Simon Willison, Hacker News (só o que passou de 150 pontos) e o fórum r/LocalLLaMA do Reddit. Tecmundo, Canaltech e Olhar Digital entram filtrados por palavras de IA. Os feeds são lidos ao mesmo tempo; se um site pede para esperar, o radar espera 8 segundos e tenta de novo uma vez.

GitHub em alta

Se o gh estiver instalado e com login, o radar busca repositórios criados nos últimos 7 dias com os termos llm, agent e ai, ordenados por estrelas, e só aproveita os que têm 300 estrelas (as "curtidas" do GitHub) ou mais. Sem o gh, essa parte só fica vazia; o resto funciona.

A nota

Cada site a mais falando do assunto vale 3 pontos; a notícia mais nova ganha até 2; fonte oficial (a empresa que lançou) soma 1,5; citar empresa ou produto conhecido soma 0,8; repositório do GitHub soma até 1,5 pelas estrelas. O total é multiplicado pelo peso da fonte, que está no fontes.json.

Variedade

No máximo 2 pautas da mesma empresa e 2 vindas só do mesmo site. Assim a lista não vira "6 notícias da OpenAI".

Pré-requisitos

O que precisa estar na máquina

Linux ou Mac (no Windows, pelo WSL, o Linux que roda dentro do Windows). Só o Python é obrigatório.

Python 3 e git (obrigatórios)

O radar usa só o que já vem com o Python: não há nada para instalar com pip (o instalador de pacotes do Python). O git baixa o projeto. Confira se os dois existem:

python3 --version && git --version

GitHub CLI (opcional)

O gh é o programa do GitHub para o terminal. Ele traz os repositórios em alta. Instale (Ubuntu: sudo apt install gh; Mac: brew install gh) e entre na sua conta uma vez:

gh auth login

Claude Code (opcional)

Só para o --angulos. O radar chama o claude -p pela sua assinatura e tira do ambiente a ANTHROPIC_API_KEY antes de chamar, para nunca cobrar por API. Instalação em claude.com/claude-code.

claude --version
Guia de uso · passo a passo

Do zero às pautas de hoje

Comandos copiáveis, na ordem.

1

Baixe o projeto

Copia o radar para a pasta ~/projetos/radar-pautas (o ~ é a sua pasta pessoal) e entra nela.

git clone https://github.com/inematds/radar-pautas ~/projetos/radar-pautas
cd ~/projetos/radar-pautas
2

Dê uma primeira olhada (sem gravar nada)

O --dry faz a rodada inteira (em geral, menos de um minuto) e só mostra o resultado na tela. Cada pauta vem com a nota entre colchetes, as fontes, há quantas horas saiu, o código do link (200 = abriu) e o endereço. No fim, quantas notícias leu e quais sites ficaram fora do ar nessa rodada.

python3 radar.py --dry
# o formato de cada pauta na tela:
1. [9.23] DeepSeek: Exploring Super-agent Design: Towards a More Autonomous Agent System
   3 fonte(s): GitHub em alta, MarkTechPost, r/LocalLLaMA · 3.9 h · 200 https://www.reddit.com/r/LocalLLaMA/...
3

Grave as pautas com o ângulo em português

Sem o --dry, o radar grava os arquivos. Com --angulos, cada pauta ganha manchete, "por que importa", gancho (a frase de abertura de um vídeo curto), formato sugerido e uma palavra para pedir nos comentários. Os formatos são os que o INEMA usa: r7ex (reel curto vertical), explicavideo (vídeo explicativo) e carrossel (post de várias imagens). Sem o Claude Code, o radar mostra aviso: ângulos não gerados e grava as pautas sem o ângulo. Se as pautas vierem sem manchete em português, abra o Claude Code uma vez (comando claude) para entrar na sua conta e rode de novo.

python3 radar.py --angulos

Se saírem menos de 3 pautas (rede fora do ar ou dia fraco), o comando termina com erro; rode mais tarde ou aumente a janela com --horas 48.

4

Abra o resultado

Fica numa pasta com a data do dia: radar.html (para abrir no navegador), pautas.md (texto) e pautas.json (para outro programa ler). Para gravar em outro lugar, rode com RADAR_SAIDA=/outra/pasta na frente do comando.

ls ~/projetos/output/radar-pautas/
xdg-open ~/projetos/output/radar-pautas/$(date +%F)/radar.html   # no Mac: open
5

Ajuste a janela e a quantidade

As opções podem ser combinadas.

OpçãoO que faz
--horas 48janela de tempo em horas (padrão 24)
--n 8quantas pautas (padrão 6)
--angulosmanchete, por que importa, gancho, formato e palavra, pelo Claude Code
--sem-githubnão busca os repositórios em alta
--drysó mostra na tela, não grava
python3 radar.py --horas 48 --n 8
6

Troque ou acrescente fontes

Abra o fontes.json num editor de texto. Cada site é uma linha, dentro da lista "ia". tipo pode ser oficial, imprensa ou comunidade; peso multiplica a nota. Antes de pôr um site novo, abra o endereço do feed no navegador e veja se ele mostra a lista de notícias. Depois de editar, o primeiro comando abaixo confere se o arquivo continua válido (uma vírgula a mais quebra tudo) e o segundo testa a rodada.

python3 -m json.tool fontes.json > /dev/null && echo ok
python3 radar.py --dry
{"nome": "The Verge", "url": "https://www.theverge.com/rss/ai-artificial-intelligence/index.xml", "tipo": "imprensa", "peso": 1.0, "lingua": "en"}
7

Aviso de "já fizemos" (opcional)

O radar procura, nas últimas 200 linhas de um arquivo de produções, uma linha que cite a mesma empresa e pelo menos 2 palavras do título; achando, a pauta ganha o aviso "Já fizemos algo parecido". O caminho vem fixo no código como ~/projetos/wifi/PRODUCOES-VIDEO.md, o arquivo do INEMA. Se ele não existe na sua máquina, o aviso simplesmente não aparece. Para usar o seu, troque o caminho na linha que começa com PRODUCOES = no radar.py e escreva no arquivo uma linha por vídeo publicado. Só contam palavras com 6 letras ou mais, e palavras genéricas (agent, model, skill, claude, openai, google, release) são ignoradas; por isso cite na linha o nome da empresa e as palavras fortes do título original da notícia (quase sempre em inglês), como no exemplo, que dispara o aviso para a pauta 1 do exemplo abaixo.

# exemplo de linha no arquivo de produções
04/11 · DeepSeek super-agent design autonomous · explicavideo publicado
grep -n "^PRODUCOES =" radar.py
8

Use pelo Claude Code (opcional)

Uma skill é um arquivo de instruções que o Claude Code carrega sozinho quando você pede algo parecido. O projeto traz a sua, o SKILL.md: com ela ligada, basta pedir as pautas na conversa. O Claude roda o radar, mostra as 6 pautas e pergunta quais viram vídeo; nada é produzido sem você escolher. Feche e abra o Claude Code depois do comando.

mkdir -p ~/.claude/skills
ln -s ~/projetos/radar-pautas ~/.claude/skills/radar-pautas
quais são as pautas de hoje?
9

Rodar todo dia às 07:30 (opcional, Linux)

A pasta systemd/ traz um agendamento pronto (um timer do systemd, o relógio de tarefas do Linux) que roda radar.py --angulos todo dia às 07:30. Ele vem desligado: só funciona depois que você copiar e ligar. Ele espera o projeto em ~/projetos/radar-pautas. Os comandos copiam o agendamento, fazem o systemd reler os arquivos (daemon-reload), ligam o timer já valendo (enable --now) e mostram quando será a próxima rodada.

mkdir -p ~/.config/systemd/user
cp systemd/radar-pautas.* ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now radar-pautas.timer
systemctl --user list-timers radar-pautas.timer

Um timer de usuário só roda enquanto você está logado. Para rodar com a máquina ligada e ninguém logado, ative uma vez: loginctl enable-linger $USER. Para desligar: systemctl --user disable --now radar-pautas.timer.

Uma rodada de verdade

Rodada de 01/11/2026 às 13:30, com --angulos: 76 notícias de 20 fontes nas últimas 24 h, Google DeepMind fora do ar nesse dia.

# trecho do pautas.md
## 1. DeepSeek mostra como montar um 'superagente' mais autônomo

- Nota 9.23 · fontes (3): GitHub em alta,
  MarkTechPost, r/LocalLLaMA · 3.9 h atrás
- Link (200): https://www.reddit.com/r/
  LocalLLaMA/comments/1xl1zn3/...
- Outras fontes: marktechpost.com/... ·
  github.com/deepseek-ai/dsh-superagent-prototype
- Por que importa: Ajuda a entender para onde
  caminham os assistentes de IA que fazem
  tarefas sozinhos, sem você guiar cada passo.
- Gancho: A DeepSeek abriu o projeto do agente
  que trabalha sozinho.
- Formato: explicavideo · palavra: superagente

A pauta 1 juntou três sites diferentes (um fórum, um site de notícias e o repositório no GitHub) e por isso ficou bem à frente da segunda, que teve 5,13 pontos.
