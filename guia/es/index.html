Los 6 temas de IA del día, con fuentes verificadas

Un comando lee 20 fuentes (blogs de empresas, prensa y foros) y las tendencias de GitHub, y muestra lo más relevante del momento. Cada tema incluye un enlace que abre y, si lo pides, un titular y un gancho en portugués.

En resumen

radar-pautas es un script (un pequeño programa que ejecutas en la terminal) que lee de una vez unos 20 sitios de noticias sobre inteligencia artificial y los proyectos que más estrellas ganaron en GitHub durante la semana. Luego, muestra los 6 temas más relevantes de las últimas 24 horas. Está pensado para quienes crean contenido y necesitan elegir rápido el tema del día. Reúne las noticias repetidas de varios sitios, les asigna una puntuación, verifica que el enlace abra y, si lo pides, sugiere un titular, un gancho y un formato en portugués. Solo necesitas Python 3; GitHub CLI y Claude Code son opcionales.

Qué es

De un aluvión de noticias a una lista breve

En lugar de abrir 20 pestañas cada mañana, ejecutas un comando y recibes 6 temas ordenados. La imagen resume las 6 etapas principales; la siguiente sección muestra el proceso completo.

📰 Una noticia, un solo tema

Cuando tres sitios hablan del mismo lanzamiento, el radar reúne todo en un tema y le da más puntos. Las noticias que aparecen en varios lugares suben; las que aparecen en un solo sitio quedan más abajo.

🔗 Solo incluye enlaces que abren

Antes de mostrar cada tema, abre su enlace. Si la página no responde «ok» (el código 200 de internet), prueba otro sitio sobre el mismo tema; si ninguno abre, el tema queda fuera.

💡 Un enfoque listo para grabar

Con --angulos, Claude Code sugiere para cada tema un titular en portugués, por qué importa, la frase inicial y el formato. Es una sugerencia: verifica el número y el dato en la fuente.

Cómo funciona

El recorrido de una ejecución

Todo se ejecuta en tu computadora. Solo lee páginas públicas (los feeds RSS de los sitios, las listas de novedades que publican) y GitHub mediante el programa gh. No necesita ninguna clave de API.

Lee 20 feeds + GitHub→ Conserva las últimas 24 h→ Reúne las noticias repetidas→ Asigna una puntuación→ Verifica el enlace→ ¿Ya lo hicimos?→ Enfoque (opcional)→ pautas.md + radar.html

Las fuentes

Están en el archivo fontes.json: blogs de OpenAI, Google AI, Google DeepMind, Hugging Face, NVIDIA, Mistral y GitHub; prensa (The Verge, TechCrunch, Ars Technica, Wired, The Decoder, MarkTechPost, MIT News); Simon Willison, Hacker News (solo lo que superó los 150 puntos) y el foro r/LocalLLaMA de Reddit. Tecmundo, Canaltech y Olhar Digital se incluyen con filtros de palabras sobre IA. Los feeds se leen al mismo tiempo; si un sitio pide que esperes, el radar espera 8 segundos y vuelve a intentarlo una vez.

Tendencias de GitHub

Si gh está instalado y tiene una sesión iniciada, el radar busca repositorios creados en los últimos 7 días que incluyan los términos llm, agent y ai, ordenados por estrellas. Solo incluye los que tienen 300 estrellas (los «me gusta» de GitHub) o más. Sin gh, esa parte queda vacía; el resto funciona.

La puntuación

Cada sitio adicional que habla del tema suma 3 puntos; la noticia más reciente obtiene hasta 2; una fuente oficial (la empresa que hizo el lanzamiento) suma 1,5; mencionar una empresa o producto conocido suma 0,8; los repositorios de GitHub suman hasta 1,5 según sus estrellas. El total se multiplica por el peso de la fuente, definido en fontes.json.

Variedad

Como máximo, 2 temas de la misma empresa y 2 que vengan solo del mismo sitio. Así la lista no termina con «6 noticias de OpenAI».

Requisitos

Qué debe estar instalado en la computadora

Linux o Mac (en Windows, mediante WSL, el Linux que se ejecuta dentro de Windows). Solo Python es obligatorio.

Python 3 y git (obligatorios)

El radar solo usa lo que ya viene con Python: no hay que instalar nada con pip (el instalador de paquetes de Python). git descarga el proyecto. Comprueba que ambos estén instalados:

python3 --version && git --version

GitHub CLI (opcional)

gh es el programa de GitHub para la terminal. Permite consultar los repositorios en tendencia. Instálalo (Ubuntu: sudo apt install gh; Mac: brew install gh) e inicia sesión una vez:

gh auth login

Claude Code (opcional)

Solo para --angulos. El radar ejecuta claude -p con tu suscripción y elimina ANTHROPIC_API_KEY del entorno antes de ejecutarlo, para que nunca se cobre por API. Instalación en claude.com/claude-code.

claude --version
Guía de uso · paso a paso

Desde cero hasta los temas de hoy

Comandos que puedes copiar, en orden.

1

Descarga el proyecto

Copia radar en la carpeta ~/projetos/radar-pautas (~ es tu carpeta personal) y entra en ella.

git clone https://github.com/inematds/radar-pautas ~/projetos/radar-pautas
cd ~/projetos/radar-pautas
2

Haz una primera prueba (sin guardar nada)

--dry ejecuta todo el proceso (por lo general, en menos de un minuto) y solo muestra el resultado en pantalla. Cada tema aparece con su puntuación entre corchetes, las fuentes, cuántas horas han pasado desde su publicación, el código del enlace (200 = abrió) y la dirección. Al final, muestra cuántas noticias leyó y qué sitios no estaban disponibles en esa ejecución.

python3 radar.py --dry
# formato de cada tema en pantalla:
1. [9.23] DeepSeek: Exploring Super-agent Design: Towards a More Autonomous Agent System
   3 fonte(s): GitHub em alta, MarkTechPost, r/LocalLLaMA · 3.9 h · 200 https://www.reddit.com/r/LocalLLaMA/...
3

Guarda los temas con el enfoque en portugués

Sin --dry, el radar guarda los archivos. Con --angulos, cada tema recibe un titular, «por qué importa», un gancho (la frase inicial de un video corto), un formato sugerido y una palabra para pedir en los comentarios. INEMA usa estos formatos: r7ex (reel vertical corto), explicavideo (video explicativo) y carrossel (publicación con varias imágenes). Sin Claude Code, el radar muestra aviso: ângulos não gerados y guarda los temas sin el enfoque. Si los temas aparecen sin un titular en portugués, abre Claude Code una vez (con el comando claude) para iniciar sesión y vuelve a ejecutar el comando.

python3 radar.py --angulos

Si aparecen menos de 3 temas (la red está caída o es un día flojo), el comando termina con un error; vuelve a ejecutarlo más tarde o amplía el período con --horas 48.

4

Abre el resultado

Se guarda en una carpeta con la fecha del día: radar.html (para abrir en el navegador), pautas.md (texto) y pautas.json (para que lo lea otro programa). Para guardarlo en otro lugar, escribe RADAR_SAIDA=/outra/pasta antes del comando.

ls ~/projetos/output/radar-pautas/
xdg-open ~/projetos/output/radar-pautas/$(date +%F)/radar.html   # en Mac: open
5

Cambia el período y la cantidad

Puedes combinar las opciones.

OpciónQué hace
--horas 48período en horas (por defecto, 24)
--n 8cantidad de temas (por defecto, 6)
--angulostitular, por qué importa, gancho, formato y palabra, mediante Claude Code
--sem-githubno busca los repositorios en tendencia
--drysolo muestra el resultado en pantalla, no lo guarda
python3 radar.py --horas 48 --n 8
6

Cambia o agrega fuentes

Abre fontes.json en un editor de texto. Cada sitio ocupa una línea dentro de la lista "ia". tipo puede ser oficial, imprensa o comunidade; peso multiplica la puntuación. Antes de agregar un sitio, abre la dirección del feed en el navegador y comprueba que muestre la lista de noticias. Después de editar, el primer comando de abajo comprueba que el archivo siga siendo válido (una coma de más puede romperlo todo) y el segundo prueba la ejecución.

python3 -m json.tool fontes.json > /dev/null && echo ok
python3 radar.py --dry
{"nome": "The Verge", "url": "https://www.theverge.com/rss/ai-artificial-intelligence/index.xml", "tipo": "imprensa", "peso": 1.0, "lingua": "en"}
7

Aviso de «ya lo hicimos» (opcional)

El radar busca en las últimas 200 líneas de un archivo de producciones una línea que mencione la misma empresa y al menos 2 palabras del título. Si la encuentra, el tema recibe el aviso «Ya hicimos algo parecido». La ruta está definida en el código como ~/projetos/wifi/PRODUCOES-VIDEO.md, el archivo de INEMA. Si no existe en tu computadora, el aviso simplemente no aparece. Para usar el tuyo, cambia la ruta en la línea que empieza con PRODUCOES = en radar.py y escribe una línea por cada video publicado. Solo cuenta las palabras de 6 letras o más; se ignoran las palabras genéricas (agent, model, skill, claude, openai, google, release). Por eso, incluye el nombre de la empresa y las palabras clave del título original de la noticia (casi siempre en inglés), como en el ejemplo, que activa el aviso para el tema 1 del ejemplo de abajo.

# ejemplo de línea en el archivo de producciones
04/11 · DeepSeek super-agent design autonomous · explicavideo publicado
grep -n "^PRODUCOES =" radar.py
8

Úsalo desde Claude Code (opcional)

Una skill es un archivo de instrucciones que Claude Code carga automáticamente cuando le pides algo parecido. El proyecto incluye la suya, SKILL.md: con ella activada, basta con pedir los temas en la conversación. Claude ejecuta el radar, muestra los 6 temas y pregunta cuáles quieres convertir en video; no se produce nada sin que tú lo elijas. Cierra y vuelve a abrir Claude Code después del comando.

mkdir -p ~/.claude/skills
ln -s ~/projetos/radar-pautas ~/.claude/skills/radar-pautas
¿cuáles son los temas de hoy?
9

Ejecútalo todos los días a las 07:30 (opcional, Linux)

La carpeta systemd/ incluye una programación lista (un timer de systemd, el reloj de tareas de Linux) que ejecuta radar.py --angulos todos los días a las 07:30. Está desactivada: solo funciona después de que la copies y la actives. Espera que el proyecto esté en ~/projetos/radar-pautas. Los comandos copian la programación, hacen que systemd vuelva a leer los archivos (daemon-reload), activan el timer de inmediato (enable --now) y muestran cuándo será la próxima ejecución.

mkdir -p ~/.config/systemd/user
cp systemd/radar-pautas.* ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now radar-pautas.timer
systemctl --user list-timers radar-pautas.timer

Un timer de usuario solo se ejecuta mientras tienes una sesión iniciada. Para que se ejecute con la computadora encendida y nadie conectado, activa una vez: loginctl enable-linger $USER. Para desactivarlo: systemctl --user disable --now radar-pautas.timer.
